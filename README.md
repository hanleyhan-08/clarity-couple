# Clarity Couple

**AI Chat Analysis Tool for Couples**

Welcome to Clarity Couple! This application helps couples understand their communication patterns by analyzing WhatsApp chat exports using AI.

## Features

- **Chat Analysis**: Upload WhatsApp conversation logs for instant AI analysis.
- **Privacy First**: 100% private. Data is processed in your session and not stored.
- **AI-Powered**: Uses Gemini Pro to provide deep insights, conflict resolution suggestions, and communication tips.
- **Neutral Mediator**: Acts as an unbiased third party to help resolve misunderstandings.

## Getting Started

1.  Clone the repository.
2.  Install dependencies:
    ```sh
    npm install
    ```
3.  Start the development server:
    ```sh
    npm run dev
    ```

## Technologies

- React
- TypeScript
- Vite
- shadcn-ui
- Tailwind CSS
